# Git & GitHub Assignment

## Objective

In this assignment, you will practice working with Git and GitHub as a team.

Your task is to:

- Clone the repository.
- Create your own branch.
- Write your code in your branch.
- Push your branch to GitHub.
- Create a Pull Request (PR).

> **Note:** Do not work directly on the `main` branch.

---

# Step 1: Clone the Repository

- Open the repository link shared by your instructor.
- Copy the repository URL.
- Open your terminal or VS Code terminal.
- Clone the repository to your computer.
- Open the cloned project in VS Code.

---

# Step 2: Create Your Own Branch

- Check which branch you are currently on.
- Create a new branch using your own name or roll number.
- Switch to your newly created branch.
- Confirm that you are working on your own branch before writing any code.

**Example Branch Names**

- `adil-ahmed`
- `student-01`
- `roll-12345`

Use a unique branch name that identifies you.

---

# Step 3: Write Your Code

- Read the assignment instructions.
- Complete the required task.
- Make sure your code is clean and properly formatted.
- Test your work before moving to the next step.

---

# Step 4: Save Your Changes

- Save all modified files.
- Check which files have changed.
- Stage the required files.
- Create a meaningful commit.

**Good Commit Message Examples**

- `Add assignment solution`
- `Complete navbar task`
- `Finish login page`

Avoid using commit messages like:

- `update`
- `test`
- `abc`

---

# Step 5: Push Your Branch

- Push **only your branch** to GitHub.
- Verify that your branch appears in the repository.

---

# Step 6: Create a Pull Request

- Open the GitHub repository.
- Select your branch.
- Click **Compare & Pull Request** (or create a new Pull Request).
- Make sure:
  - **Base Branch:** `main`
  - **Compare Branch:** Your branch
- Add a clear title.
- Write a short description of your work.
- Submit the Pull Request.

---

# Before You Submit

Make sure you have completed all of the following:

- Repository cloned
- Personal branch created
- Code completed
- Changes committed
- Branch pushed to GitHub
- Pull Request created

---

# Important Rules

- Do **not** push directly to the `main` branch.
- Work only on your own branch.
- Do not delete or modify another student's work.
- Keep your commit messages meaningful.
- Create only one Pull Request unless instructed otherwise.

---

# Submission

Your assignment will be considered submitted **only after your Pull Request has been created.**

Good luck and happy coding! 🚀
